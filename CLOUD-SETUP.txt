Cloud monitoring is not activated by deploying the static site. Export a watchlist from Mission, then place it and cloud-worker.py on a trusted Python host. Set SEARCH_PROXY to a compatible HTTPS search endpoint. Schedule python cloud-worker.py watchlist.json results.json using the host scheduler. Retrieve results.json and import it in the same case. The worker checks up to 50 queries per run; review errors in the output. No notifications or automatic synchronization are configured. Queries are disclosed to the chosen proxy. Keep sensitive case data out of public hosting. Do not upload watchlist or results to the public Netlify folder.

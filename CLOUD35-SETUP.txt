Deploy the static app as before. For actual background operation, run cloud35.py on a private persistent Python 3 host behind an HTTPS reverse proxy forwarding to localhost:8080. Set ART_TOKEN to a random secret of at least 32 characters, ART_ORIGIN to your exact Netlify origin (no trailing slash), SEARCH_PROXY to a compatible HTTPS endpoint, ART_DB to a private persistent database path, and optionally ART_INTERVAL (seconds, minimum 900) and ART_WEBHOOK (HTTPS endpoint accepting JSON text). Keep secrets and database outside the public website. Run python cloud35.py under a service supervisor. In Autonomous enter the HTTPS service URL and token, publish watchlist, then synchronise after a scan. Empty watchlist stops future searches for that case. Case titles are keys; avoid duplicate titles. Notifications are best effort, not retried. Search proxy costs and limits apply. AI review is an export for external interpretation, not an integrated AI service. No cloud service is provisioned by this package.
